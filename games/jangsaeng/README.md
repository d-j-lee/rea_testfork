# 장생(長生): 오백년

> 고려의 황혼에서 대한제국의 끝까지, 오백 년을 살아낸 무신의 MMORPG — 웹 시제품

1361년, 홍건적에 개경이 무너진 밤. 노인성(老人星)의 빛을 받은 열여섯 살 무사는 오백 년의 천수를 얻는다. 무신으로 공을 세워 **조선의 개국공신**이 되고, 늙지 않는 얼굴을 새 이름으로 숨기며 **사화와 환국, 임진·병자의 전란**을 견딘다. 그리고 마지막 열네 해에는 쌓아 온 인연과 국운으로 **국권 상실을 막을 수 있는지** 시험한다.

이 게임은 실제 역사에 바탕을 둔 대체역사 픽션입니다. 실존 인물과 사건은 사료를 존중해 묘사했으며, 가상의 주인공과 선택에 따른 전개는 창작입니다.

## 핵심 재미

| 기둥 | 플레이 |
|---|---|
| 오백 년을 자원으로 | 천수는 1861년에 끝난다. 1910년에 닿으려면 공덕·대전(大戰) 승리·산삼으로 수명을 벌어야 하고, 비장기 '노인성 일섬'은 수명 1년을 태운다. |
| 정치와 신분 | 늙지 않는 얼굴은 의심을 부른다. 30~40년마다 신분을 세탁하고, 숙청이 닥칠 때마다 '풍향계'로 위험을 읽고 편을 고른다. |
| 역사 속 대전 | 황산, 위화도, 한산·명량 갑판전, 행주, 남한산성, 정족산성, 중명전까지. 실시간 탑다운 전투이고, 무기는 환도에서 신기전·조총·소총으로 바뀐다. |
| 함께 쓰는 실록 (MMO) | 같은 시대에 선 장생인끼리 시대 채널을 공유하고, 함께 싸우고 서로 살린다. 채널의 공동 실록이 모두의 엔딩에 반영된다. |

1910년, 1802~1907년의 분기점 B1~B12c(14개)에서 쌓은 결과로 국가 엔딩 3종과 개인 엔딩 6종이 정해진다.

## 바로 해보기

- **단일 파일(오프라인)**: `npm run build` 후 `dist/jangsaeng.html`을 브라우저로 연다. 시뮬레이션 동료(◇) 8명이 채널을 채운다. 혼자 쓰는 세계라서 메뉴 책·휴대폰 서랍·채팅 입력·오류 화면이 열려 있는 동안 멈춘다(온라인 세계는 멈추지 않는다).
- **온라인 서버**:

  ```sh
  npm ci
  npm run build
  npm start          # http://localhost:8080 — 같은 주소로 여러 브라우저가 접속하면 같은 시대 채널에서 만난다
  ```

  환경 변수: `PORT`(8080), `HOST`(0.0.0.0), `DATA_DIR`(./data), `BOTS`(채널당 ◇동료 수, 기본 8 — 전투 밸런스의 기준인 `DEFAULT_COMPANIONS`. 2명으로는 대전을 자주 진다: 측정에서 명량 2/3, 남한산성 1/3), `SEED`(jangsaeng). 채널 정원은 40명이고, 넘치면 새 샤드가 열린다.
- **시연 모드**: 제목 화면의 '시연 모드'에서 16개 장 가운데 하나를 골라 프리셋 인물로 바로 시작한다.
  - '역사 경로'는 실제 역사의 국운에서 출발하고, 앞선 장의 분기는 모두 실패한 것으로 둔다. '개혁 누적'은 앞선 장의 분기를 모두 지켜 내고 장기 국운과 이야기 플래그를 가장 좋은 값으로 가진 채 출발한다. 제16장은 역사 경로에서 N3, 개혁 누적에서 N1로 이어진다.
  - 제16장은 1904년 장면(B11 결정)에서 열린다. 그 앞 단계는 게임이 시연자의 건너뛰기로 대신 처리하므로, 세이브는 처음부터 건너뛴 것과 같다.
  - 시연 중에는 '건너뛰기'가 누른 사람에게만 적용된다. 열린 카드는 첫 선택지로 답하고, 전투는 먼저 시연자와 ◇동료를 전장으로 데려가 시작한 뒤 다음 누름에 이긴다. 쓰러져 있으면 먼저 스스로 일어난다(장의 첫 소생 뒤에는 천수 1년이 든다).
  - 시연 인물의 시드는 장과 경로에서 나온다. 같은 장·경로를 다시 시연하면 판정·숙청·풍향계·이름이 매번 같다.
  - 프리셋 인물은 1361년부터 약 35년마다 신분을 세탁한 이력과 앞선 장들의 전투·소생 기록을 가지고 시작한다(제4장까지는 세탁 이력이 없다).
  - 시연 인물은 실제 세이브와 섞이지 않게 시연 전용 채널(`ch16#demo1` 꼴)을 쓴다.

요구 사항: Node.js 22.18 이상(TypeScript를 빌드 없이 실행).

## 조작

| | 키보드·마우스 | 터치 | 게임패드(표준 매핑) |
|---|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽을 끄는 가상 스틱 | 왼쪽 스틱 |
| 공격(3연격, 누르고 있으면 이어 친다) | J · Space · 왼쪽 클릭 | 오른쪽 큰 버튼 | A |
| 활(누르고 있으면 당기고, 떼면 쏜다) | K · 오른쪽 클릭 | 오른쪽 큰 버튼 | X |
| 구르기(누를 때마다 한 번) | Shift · L | 원호의 버튼 | B |
| 기술 1~4(누를 때마다 한 번) | 1~4 | 원호 바깥의 작은 버튼 | LB · RB · LT · RT |
| 노인성 일섬(누를 때마다 한 번) | 5 · R | 원호 바깥의 작은 버튼 | — |
| 대화·상호작용(누를 때마다 한 번) | E · F | 원호의 버튼 | Y |
| 인물 · 소지품 · 지도 · 국운 · 연대기 | C · I · M · N · T | 소지도 아래 ≡ 메뉴 | — |
| 채팅 / 도움말 / 메뉴 / 음소거 | Enter / F1 · / / Esc / O | 메뉴 | — |
| 선택지 고르기 | 1~9 · 클릭 | 누르기 | — |

기술·일섬·상호작용은 키를 누르고 있어도 다시 나가지 않는다(키보드 자동 반복은 무시하고, 게임패드는 누른 순간에만 반응한다).

쓰러지면 사경(死境)에 빠진다. 동료를 기다리거나 자력 소생으로 일어서고(장마다 첫 소생 무료, 이후 천수 1년), 전투 중이면 링 가장자리에서 일어나 계속 싸운다. 전투에서 지면 쓰러져 있던 사람은 링 가장자리에서 체력 25%로 일어나 물러난다(천수를 쓰지 않는다). 진 전투는 저절로 다시 열리지 않고, 전장 밖으로 나갔다가 돌아오면 다시 싸운다.

## 개발

```sh
npm ci
npm run dev          # 클라이언트 감시 빌드 + 서버 자동 재시작
npm run typecheck    # shared / client / server / tools 네 설정
npm test             # 단위·통합 테스트(전체 아크 자동 진행, 호스트 전투, 시연 진입 포함)
npm run build        # dist/client + dist/jangsaeng.html
npm run test:e2e     # 헤드리스 Chromium 스모크(--device=laptop|phone)
node tools/preview/ui-check.mjs                 # UI 상호작용 점검
node scripts/preview.mjs <entry.ts> <out.png>   # 렌더·UI 시각 확인
```
