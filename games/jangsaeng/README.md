# 장생(長生): 오백년

> 고려의 황혼에서 대한제국의 끝까지, 오백 년을 살아낸 무신의 MMORPG — 웹 시제품

1361년, 홍건적에 개경이 무너진 밤. 노인성(老人星)의 빛을 받은 열여섯 살 무사는 오백 년의 천수를 얻는다. 무신으로 공을 세워 **조선의 개국공신**이 되고, 늙지 않는 얼굴을 새 이름으로 숨기며 **사화와 환국, 임진·병자의 전란**을 견딘다. 그리고 마지막 열네 해에는 쌓아 온 인연과 국운으로 **국권 상실을 막을 수 있는지** 시험한다.

이 게임은 실제 역사에 바탕을 둔 대체역사 픽션입니다. 실존 인물과 사건은 사료를 존중해 묘사했으며, 가상의 주인공과 선택에 따른 전개는 창작입니다.

## 핵심 재미

| 기둥 | 플레이 |
|---|---|
| 오백 년을 자원으로 | 천수는 1861년에 끝난다. 1910년에 닿으려면 공덕·대전(大戰) 승리·산삼으로 수명을 벌어야 하고, 비장기 '노인성 일섬'은 수명 1년을 태운다. |
| 정치와 신분 | 늙지 않는 얼굴은 의심을 부른다. 30~40년마다 신분을 세탁하고, 숙청이 닥칠 때마다 '풍향계'로 위험을 읽고 편을 고른다. |
| 역사 속 대전 | 황산, 위화도, 한산·명량 갑판전, 행주, 남한산성, 정족산성, 중명전까지. 실시간 탑다운 전투이고, 무기는 환도에서 신기전·조총·소총으로 바뀐다. |
| 함께 쓰는 실록 (MMO) | 같은 시대에 선 장생인끼리 시대 채널을 공유하고, 함께 싸우고 서로 살린다. 채널의 공동 실록이 모두의 엔딩에 반영된다. |

1910년, 분기점 B1~B12에서 쌓은 결과로 국가 엔딩 3종과 개인 엔딩 6종이 정해진다.

## 바로 해보기

- **단일 파일(오프라인)**: `npm run build` 후 `dist/jangsaeng.html`을 브라우저로 연다. 시뮬레이션 동료(◇)가 채널을 채운다.
- **온라인 서버**:

  ```sh
  npm ci
  npm run build
  npm start          # http://localhost:8080 — 같은 주소로 여러 브라우저가 접속하면 같은 시대 채널에서 만난다
  ```

  환경 변수: `PORT`(8080), `HOST`(0.0.0.0), `DATA_DIR`(./data), `BOTS`(채널당 동료 수, 2), `SEED`(jangsaeng).
- **시연 모드**: 제목 화면의 '시연 모드'에서 16개 시대 중 하나를 골라 프리셋 인물로 바로 시작한다. '역사 경로'는 실제 역사의 국운에서, '개혁 누적'은 앞선 장의 분기를 지켜 낸 국운에서 출발한다(제16장 기준 역사 경로는 N3, 개혁 누적은 N1로 이어진다). 시연 중에는 '건너뛰기'로 목표와 전투를 넘길 수 있다.

요구 사항: Node.js 22.18 이상(TypeScript를 빌드 없이 실행).

## 개발

```sh
npm ci
npm run dev          # 클라이언트 감시 빌드 + 서버 자동 재시작
npm run typecheck    # shared / client / server 세 설정
npm test             # 단위·통합 테스트(전체 아크 자동 진행 포함)
npm run build        # dist/client + dist/jangsaeng.html
npm run test:e2e     # 헤드리스 Chromium 스모크
node scripts/preview.mjs <entry.ts> <out.png>   # 렌더·UI 시각 확인
```
