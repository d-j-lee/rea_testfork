# 장생 로드맵

이 문서는 시제품이 지금 무엇을 증명하는지, 무엇이 아직 비어 있는지, 다음에 무엇을 할지를 적는다. 설계 수치는 [GDD.md](GDD.md), 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 고증 기준은 [HISTORY.md](HISTORY.md)가 맡는다.

## 1. 시제품이 증명하는 것

| 질문 | 시제품의 답 | 확인 방법 |
|---|---|---|
| 500년 아크가 한 판으로 이어지는가 | 1361년 노인성의 밤에서 1910년 정산까지 16장이 끊김 없이 이어지고 엔딩에 닿는다. | `npm test`의 전체 아크 자동 진행, 장별 시연 완주 테스트 |
| 선택이 결말을 바꾸는가 | 같은 제16장도 역사 경로에서는 N3, 개혁 누적 경로에서는 N1로 끝난다. | `host.test.ts` "the demo path decides where CH16 can lead" |
| 탑다운 실시간 전투가 시대마다 달라지는가 | 환도·활에서 신기전·조총·소총까지, 갑판전·수성전·보스전·결투가 있다. | `world-battle.test.ts`, 시연 모드 |
| MMO 구조가 서는가 | 같은 시대의 장생인이 채널을 공유하고 서로 보이며, 채팅·동행 전투·공동 실록이 작동한다. | 실서버에 WebSocket 클라이언트 2개, 브라우저 2개로 접속 확인(아래 검증 범위) |
| 웹에서 바로 열리는가 | 외부 에셋 없이 단일 HTML 하나(약 1.2 MB)로 오프라인 실행된다. 데스크톱과 휴대폰 화면 모두 지원한다. | `tests/e2e/run.mjs --device=laptop|phone`, `tools/preview/ui-check.mjs` |

## 2. 검증 범위와 한계

검증한 것:
- 단위·통합 테스트: 지도, 물리, 콘텐츠 참조 무결성, 모든 장의 도보 도달성, 규칙, 전투, 호스트(시연 완주·전체 아크·카드 연도·시연 경로).
- 헤드리스 Chromium에서 데스크톱(1280×720)과 휴대폰(390×844, 터치) 스모크.
- 실서버(`npm start`)에 클라이언트 2개를 붙여 확인: 같은 채널 배정, 상호 표시, 10 Hz 스냅숏, 채팅 전달, 온라인 이름 중복 거절, 토큰 재접속 시 이전 연결 교체, 메시지 폭주·과대 메시지 차단.

검증하지 않은 것:
- 실제 휴대폰(iOS Safari, Android Chrome)에서의 터치감, 안전 영역, 오디오 잠금 해제. Chromium 에뮬레이션만 확인했다.
- 사람이 직접 들어 본 음악·효과음의 품질.
- 원거리 지연 환경의 온라인 체감. 클라이언트 예측이 없어서 지연이 그대로 입력 반응에 드러난다.
- 동시 접속 수십 명 이상의 부하.

## 3. 알려진 한계

| 영역 | 한계 | 다음 조치 |
|---|---|---|
| 네트워크 | 클라이언트 측 예측·보정이 없다(온라인 10 Hz 스냅숏 보간만). | 이동 예측과 서버 보정 |
| 네트워크 | 화면 흔들림 같은 효과 이벤트에 수신자 지정이 없어 반경 안의 모두에게 간다. | `FxEvent`에 대상 필드 |
| 콘텐츠 | 동료 작별 카드(세월이 흘러 ◇동료가 늙어 떠나는 장면)는 설계만 있다. | 세월 흐르기 결과에 작별 카드 |
| 콘텐츠 | 일부 사실은 전문가 검토가 필요하다. | [HISTORY.md](HISTORY.md)의 검토 목록 |
| 표현 | 한자 붓글씨 글꼴은 Google Fonts의 일본어 붓글씨체를 필요한 글자만 받아 쓴다. 한국 붓글씨체로 바꿀지 결정이 필요하다. | 글꼴 후보 비교 |
| 운영 | 프로필은 서버 디스크의 JSON 파일이다. 계정·인증·백업이 없다. | 계정과 DB 저장소 |

## 4. 다음 단계

1. **v0.3 온라인 체감**: 이동 예측, 재접속 시 상태 복구 연출, 채널 이동 UI, 원거리 지연 시험.
2. **v0.4 콘텐츠 깊이**: 장마다 부가 임무와 반복 가능한 전투, 동료 작별 카드, 시대별 생활 활동(장터·과거 시험·사냥).
3. **v0.5 제작 기반**: 계정·DB·관리 도구, 부정행위 방지(서버 판정 범위 점검), 지표 수집.
4. **외부 검토**: 역사 자문, 사용성 시험(장르 경험자와 비경험자), 휴대폰 실기기 시험.

## 5. 결정이 필요한 것

- 전용 저장소로 분리할지(지금은 `games/jangsaeng/` 하위 패키지).
- 아트 방향: 지금의 절차적 픽셀 아트를 다듬을지, 일러스트 리소스로 바꿀지.
- 서비스 형태: 웹 우선 무료 체험과 정식판의 범위.
