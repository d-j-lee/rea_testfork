# 장생 로드맵

이 문서는 시제품이 지금 무엇을 증명하는지, 무엇이 아직 비어 있는지, 다음에 무엇을 할지를 적는다. 설계 수치는 [GDD.md](GDD.md), 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 고증 기준은 [HISTORY.md](HISTORY.md)가 맡는다. 코드 위치는 `src/shared/` 기준으로 적는다.

## 1. 시제품이 증명하는 것

## 2. 검증 범위와 한계

자동 검사가 덮는 것:
- 단위·통합 테스트(`npm test`): 지도와 도보 도달성(명량 링에 걸을 수 있는 해안이 없음 포함), 물리, 규칙(효과·엔딩 정산·신분·수명·정치·성장·세이브와 이전·세월, 세월 계획의 예상 천수가 실제 세월 흐르기와 같음, 조사, 침투도 설명), 월드 전투(참가자·전장 땅·다인 보정·사기·갑판·결투·링 가장자리 소생·패배 철수), 개경 북문·명량·남한산성의 템포, 콘텐츠 계약 네 파일, 호스트(전체 아크, 시연 경로와 콜드 오픈, 시연 시드, 시연 계획표의 마지막 은혜, 밀린 카드의 재접속, 정산 뒤 고정, 세월 계획의 마지막 은혜와 제안 이름), 호스트 전투(이야기 시작, 패배 철수와 재시작, 건너뛰기, 온라인 두 사람, 레벨업 알림 하나, ◇동료의 도착 분산과 채팅 제한), 서버 속도 관문, 클라이언트 이름표·문구·저장·세계 멈춤 시계·천수 경고 단계.
- 타입 검사 네 설정(shared·client·server·tools)과 단일 파일 빌드.
- 브라우저: 헤드리스 Chromium에서 노트북(1280×720)과 휴대폰(390×844, 터치 에뮬레이션) 스모크(`tests/e2e/run.mjs`), UI 상호작용 점검(`tools/preview/ui-check.mjs`: 설정 저장과 실패한 쓰기, 모달 아래 토스트 보류와 독, 메뉴 책의 세계 멈춤, 긴 결과 카드의 '계속', 대체역사 리본, 사경 화면과 자력 소생 패, 천수 경고 단계, 세월 계획 전송과 첫 화면의 봉헌 스위치·새 이름 칸, 시연 격자, 지도 이름 겹침, 휴대폰 메뉴 탭, 제목·도움말 문구, 엔딩).

측정(시제품 프로브: 실제 `Channel`·`Session`·`Bot`, 사람 1·◇동료 8, 시연 건너뛰기로 그 단계까지, 시드 6개):
- 개경 북문 6/6 승(시드를 12개로 늘려도 12/12), 24~31초.
- 명량 6/6 승, 적장이 약 28초에 오르고 평균 53초에 이긴다.
- 남한산성 6/6 승, 그중 5번은 적장(75초에 등장)을 쓰러뜨려 106~120초에 끝났다.
- 행주 4/4 승, 약 28~33초(앞선 측정).
- ◇동료 2명(시드 3개): 북문 3/3, 명량 2/3, 남한산성 1/3. 그래서 ◇동료 기본값을 오프라인과 서버 모두 8로 정했다(`host/api.ts#DEFAULT_COMPANIONS`).
- ◇동료 채팅은 분당 15~75줄에서 3~11줄로 줄었다(`host/bots.ts` `LINE_GAP`, `host/channel.ts` `BOT_CHAT_GAP`).
- 북문·명량과 ◇동료 2명 수치는 ◇동료가 적장을 노리기(`WorldQuery.battleBoss`) 전에 쟀다. 그 뒤에 다시 잰 것은 남한산성뿐이다.
- 헤드리스 Chromium 소프트웨어 렌더링, 명량(안개): 안개·연기를 1/8 크기 층에 합성한 뒤(`src/client/render/lighting.ts` `cloudLayerFor`) 노트북 34~41 → 47~57 fps, 휴대폰 25~28 → 30~48 fps.

검증하지 않은 것:
- 실제 휴대폰(iOS Safari, Android Chrome)의 터치감, 안전 영역, 오디오 잠금 해제. Chromium 에뮬레이션만 확인했다.
- 실제 GPU와 실기기의 프레임 시간. 위 fps는 헤드리스 소프트웨어 렌더링 값이다. 장 진입 첫 프레임이 250~640ms 걸리는 것(장 카드가 가린다)도 헤드리스에서만 보았다.
- 사람이 직접 들어 본 음악·효과음의 품질. 오디오는 사람이 검토한 적이 없다.
- 원거리 지연 환경의 온라인 체감과 동시 접속 수십 명 이상의 부하.
- 전투 하늘 섞기의 휴대폰 비용. 전투의 날씨가 장과 다르면, 하늘이 옅어지는 띠(링 반경 + 6~12타일)와 1.5초 전환 동안 매 프레임 대기 효과를 세 번 그린다(`src/client/game/scene.ts` `drawSky`). 그 프레임 시간을 재지 않았다.
- ◇동료 없이 혼자 싸우는 대전의 승률. 재지 않았다.
- 사람 플레이어가 진 전투의 무료 철수를 자력 소생 비용을 피하는 데 쓰는지. 플레이 시험이 없다.

## 3. 알려진 한계

|---|---|---|
| 전투 | 혼자 싸우는 대전: ◇동료가 없으면 쓰러지는 순간 모든 참가자가 쓰러진 것이 되어 진다(`sim/battle.ts#lost`). 자력 소생이 그 전투를 구하지 못하고, 철수로 일어선다. ◇동료 2명으로도 명량 2/3, 남한산성 1/3이다. | 일으켜 줄 사람이 없을 때 사경 시간 안에 자력 소생할 기회를 줄지, 대전 난이도를 인원에 맞출지 결정 |

| 접근성 | 토스트는 화면 위 묶음과 독이 각각 알림 영역이다. 오류를 독으로 옮길 때 보조 기술에서 숨기므로, 같은 순간에 옮겨진 오류는 읽히지 않을 수 있다(`src/client/ui/toasts.ts`). | 보이지 않는 알림 전담 영역 하나가 읽기를 맡기 |
| 운영 | 프로필은 서버 디스크의 JSON 파일이다. 계정·인증·백업이 없다. | 계정과 DB 저장소 |
