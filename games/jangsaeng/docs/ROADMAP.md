# 장생 로드맵

이 문서는 시제품이 지금 무엇을 증명하는지, 무엇이 아직 비어 있는지, 다음에 무엇을 할지를 적는다. 설계 수치는 [GDD.md](GDD.md), 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 고증 기준은 [HISTORY.md](HISTORY.md)가 맡는다. 코드 위치는 `src/shared/` 기준으로 적는다.

## 1. 시제품이 증명하는 것

| 질문 | 시제품의 답 | 확인 방법 |
|---|---|---|
| 500년 아크가 한 판으로 이어지는가 | 1361년 노인성의 밤에서 1910년 정산까지 16장이 끊김 없이 이어지고 엔딩에 닿는다. | `tests/unit/host.test.ts`의 전체 아크 자동 진행, `host-battle.test.ts`의 모든 장·단계·경로 시연 진입 |
| 선택이 결말을 바꾸는가 | 같은 제16장도 역사 경로에서는 N3, 개혁 누적 경로에서는 N1로 끝난다. | `host.test.ts` "the demo path decides where CH16 can lead" |
| 탑다운 실시간 전투가 시대마다 달라지는가 | 환도·활에서 신기전·조총·소총까지, 갑판전·수성전·보스전·결투·생존전·탈출전이 있다. 적장이 있는 전투는 적장이 쓰러진 뒤에야 무너진다. | `world-battle.test.ts`, `world-pacing.test.ts`, 시연 모드, 아래 측정 |
| MMO 구조가 서는가 | 같은 시대의 장생인이 채널을 공유하고 서로 보인다. 링 곁에서 기다린 사람도 전투 결과를 받고, 이미 이긴 사람은 재도전에 끌려 들어가지 않는다. 채팅·동행 전투·공동 실록이 작동한다. | `host-battle.test.ts` "online, two people", `host.test.ts` 채널 멤버 테스트 |
| 웹에서 바로 열리는가 | 단일 HTML 하나(약 1.3 MB)로 오프라인 실행된다. 데스크톱과 휴대폰 화면을 모두 지원한다. | `tests/e2e/run.mjs --device=laptop|phone`, `tools/preview/ui-check.mjs` |

## 2. 검증 범위와 한계

자동 검사가 덮는 것:
- 단위·통합 테스트(`npm test`): 지도와 도보 도달성, 물리, 규칙(효과·엔딩 정산·신분·수명·정치·성장·세이브와 이전·세월), 월드 전투(참가자·전장 땅·다인 보정·사기·갑판·결투·링 가장자리 소생), 콘텐츠 계약 네 파일, 호스트(전체 아크, 시연 경로와 콜드 오픈, 밀린 카드의 재접속, 정산 뒤 고정, 세월 계획의 마지막 은혜와 제안 이름), 호스트 전투(이야기 시작, 건너뛰기, 온라인 두 사람), 서버 속도 관문, 클라이언트 이름표·문구·저장.
- 타입 검사 네 설정(shared·client·server·tools)과 단일 파일 빌드.
- 브라우저: 헤드리스 Chromium에서 노트북(1280×720)과 휴대폰(390×844, 터치 에뮬레이션) 스모크(`tests/e2e/run.mjs`), UI 상호작용 점검(`tools/preview/ui-check.mjs`: 설정 저장과 실패한 쓰기, 토스트 보류와 독, 세월 계획 전송, 제목·도움말 문구, 엔딩).

측정(시제품 프로브, 사람 1·◇동료 8):
- 명량 4/4 승, 51~89초, 다섯 웨이브를 모두 지난 뒤 적장과 싸운다.
- 남한산성 6/6 승, 150초를 버티고 화톳불이 10~31% 남는다.
- 행주 4/4 승, 약 28~33초.
- ◇동료 2명으로는 남한산성 0/3, 명량 1/3이다. 그래서 ◇동료 기본값을 오프라인과 서버 모두 8로 정했다(`host/api.ts#DEFAULT_COMPANIONS`).

검증하지 않은 것:
- 실제 휴대폰(iOS Safari, Android Chrome)의 터치감, 안전 영역, 오디오 잠금 해제. Chromium 에뮬레이션만 확인했다.
- 사람이 직접 들어 본 음악·효과음의 품질. 오디오는 사람이 검토한 적이 없다.
- 원거리 지연 환경의 온라인 체감과 동시 접속 수십 명 이상의 부하.
- 전투 하늘 섞기의 휴대폰 비용. 전투의 날씨가 장과 다르면, 하늘이 옅어지는 띠(링 반경 + 6~12타일)와 1.5초 전환 동안 매 프레임 대기 효과를 세 번 그린다(`src/client/game/scene.ts` `drawSky`). 그 프레임 시간을 재지 않았다.

## 3. 알려진 한계

| 영역 | 한계 | 다음 조치 |
|---|---|---|
| 전투 | 혼자 싸우는 대전: ◇동료가 없으면 쓰러지는 순간 모든 참가자가 쓰러진 것이 되어 진다(`sim/battle.ts#lost`). 자력 소생이 그 전투를 구하지 못한다. | 일으켜 줄 사람이 없을 때 사경 시간 안에 자력 소생할 기회를 줄지 결정 |
| 네트워크 | 클라이언트 측 예측·보정이 없다(온라인 10 Hz 스냅숏 보간만). 지연이 그대로 입력 반응에 드러난다. | 이동 예측과 서버 보정 |
| 네트워크 | 서버가 속도 관문 때문에 메시지를 한 번 해석하고(`src/server/main.ts`), 호스트가 다시 해석한다(`host/host.ts`). 두 번째 해석이 바꾸는 것이 없다는 것은 표본 메시지로만 확인한다. | 호스트 연결이 해석된 메시지를 받게 해 한 번만 해석 |
| 네트워크 | 예산을 넘긴 1초 창에서는 스틱·조준 변화가 그 창이 끝날 때까지 늦을 수 있다(버튼 변화는 잃지 않는다, `src/server/rate.ts`). | 버리지 않고 마지막 입력으로 합치기 |
| 네트워크 | 화면 흔들림 같은 효과 이벤트에 수신자 지정이 없어 반경 안의 모두에게 간다. | `FxEvent`에 대상 필드 |
| 시연 | 조용한 콜드 오픈(`host/session.ts` `#playDemoEntry`)은 시연자 화면만 조용하다. 같은 시연 샤드의 다른 사람에게는 건너뛴 단계의 전투 시작 알림·◇동료 반응·공동 실록 진행이 한꺼번에 간다. 실제 세이브와는 샤드가 달라 닿지 않는다. | 채널 수준의 조용한 범위를 둘지 결정 |
| 시연 | 쓰러진 시연자의 건너뛰기는 자력 소생 규칙을 그대로 따라, 장의 첫 소생 뒤에는 천수 1년을 쓴다. | 시연에서 비용을 면제할지 결정 |
| 콘텐츠 | 동료 작별 카드(세월이 흘러 ◇동료가 늙어 떠나는 장면)는 설계만 있다. | 세월 흐르기 결과에 작별 카드 |
| 콘텐츠 | ch12 환국의 승자 편 선택지도 숙청을 판정한다. 작업용 GDD의 대안(승자 진영에 서고 공적 +20, 판정 없음)은 고르지 않았다(GDD 8장). | 콘텐츠 책임자 결정 |
| 콘텐츠 | 일부 사실은 전문가 검토가 필요하다. | [HISTORY.md](HISTORY.md)의 검토 목록 |
| 접근성 | 토스트는 화면 위 묶음과 아래 독이 각각 알림 영역이다. 오류를 독으로 옮길 때 보조 기술에서 숨기므로, 같은 순간에 옮겨진 오류는 읽히지 않을 수 있다(`src/client/ui/toasts.ts`). | 보이지 않는 알림 전담 영역 하나가 읽기를 맡기 |
| 표현 | 자력 소생 버튼은 이번 소생의 정확한 비용이 아니라 규칙 문구('장마다 첫 소생 무료 · 이후 천수 −1년')를 보인다. | `SelfView.downed`에 이번 비용 |
| 표현 | 한자 붓글씨 글꼴은 Google Fonts의 일본어 붓글씨체(Yuji Syuku)를 필요한 글자만 받아 쓴다(`src/client/index.html`). 한국 붓글씨체로 바꿀지 결정이 필요하다. | 글꼴 후보 비교 |
| 운영 | 프로필은 서버 디스크의 JSON 파일이다. 계정·인증·백업이 없다. | 계정과 DB 저장소 |

## 4. 다음 단계

1. **v0.3 온라인 체감**: 이동 예측, 한 번만 해석하는 메시지 경계, 재접속 시 상태 복구 연출, 채널 이동 UI, 원거리 지연 시험.
2. **v0.4 콘텐츠 깊이**: 장마다 부가 임무와 반복 가능한 전투, 동료 작별 카드, 시대별 생활 활동(장터·과거 시험·사냥).
3. **v0.5 제작 기반**: 계정·DB·관리 도구, 부정행위 방지(서버 판정 범위 점검), 지표 수집.
4. **외부 검토**: 역사 자문, 사용성 시험(장르 경험자와 비경험자), 휴대폰 실기기 시험, 음악·효과음 청취 검토.

## 5. 결정이 필요한 것

- 혼자 싸우는 대전에서 자력 소생으로 전투를 이어 갈 수 있게 할지.
- ch12 환국 승자 편 선택지를 작업용 GDD 안으로 바꿀지.
- 시연 콜드 오픈의 채널 방송을 막을지, 시연 건너뛰기의 소생 비용을 면제할지.
- 한자 붓글씨 글꼴(일본어 붓글씨체 부분 집합을 유지할지, 한국 붓글씨체로 바꿀지).
- 전용 저장소로 분리할지(지금은 `games/jangsaeng/` 하위 패키지).
- 아트 방향: 지금의 절차적 픽셀 아트를 다듬을지, 일러스트 리소스로 바꿀지.
- 서비스 형태: 웹 우선 무료 체험과 정식판의 범위.
