# [기획서] 일일 미션 개편 v1.2

- 작성: 컨텐츠기획팀 / 대상 빌드: 1.4.3 / 서비스: 글로벌(스팀)

## 1. 개요
매일 갱신되는 일일 미션 3종을 제공하고, 달성 시 골드/아이템 보상을 지급한다. 접속 동기 부여와 매치 참여율 상승이 목표다.

## 2. 미션 구성
| 미션 ID | 이름 | 목표 | 보상 |
| --- | --- | --- | --- |
| 101 | 일일 접속 | 접속 1회 | 골드 100 |
| 102 | 매치 5회 완료 | 매치 완료 5회 | 골드 500 |
| 103 | 헤드샷 20회 | 헤드샷 킬 20회 | 골드 800 |
| 104 | (이벤트) 클랜전 1회 | 클랜전 참여 1회 | 보급상자(아이템 9001) |

- 레벨 10 미만 유저에게는 101번 미션만 노출한다.
- 이벤트 기간 중에는 골드 보상이 2배가 된다. (이벤트 기간: 11/1 ~ 11/7)
- 미션 데이터는 `mission_table.xlsx`를 따른다.

## 3. 초기화
- 일일 미션은 **매일 00:00(UTC)에 초기화**된다. 공지에도 동일하게 안내한다.
- 초기화 시 미달성 진행도는 사라진다.

## 4. 수령
- 미션 달성 후 미션 창의 [보상 받기] 버튼으로 수령한다. 미션별 **1일 1회**.
- 아이템 보상은 인벤토리가 가득 차면 우편으로 지급한다.

## 5. 진행도 집계
- "매치 완료"는 매치가 정상 종료되었을 때 1회로 센다.
- 헤드샷 킬은 모든 모드에서 집계한다.

## 6. 기타
- 운영 중 문제가 생기면 GM 툴로 대응한다.
