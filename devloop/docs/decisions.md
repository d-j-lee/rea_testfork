# 설계 결정 기록 (ADR)

결정, 대안, 근거만 남긴다. 현재 구조의 설명은 [architecture.md](architecture.md)가 소유한다.
뒤집힌 결정은 지우지 않고 `대체됨`으로 표시한다.

| # | 결정 | 고려한 대안 | 근거 | 상태 |
| --- | --- | --- | --- | --- |
| D1 | Claude Code **플러그인**으로 배포 (skills·agents·hooks·CLI 동봉) | `.claude/`에 파일 복사, 사내 위키 프롬프트 | 팀 단위 버전 관리·설치·업데이트의 표준 경로. 마켓플레이스가 막혀 있으면 `~/.claude/skills/<name>/` 자동 로드(skills-dir) 사용 | 채택 |
| D2 | 도구는 **표준 라이브러리 Python CLI** (3.11+) | Node/TS, 외부 의존성 | 사내 PC·서버(Windows 포함)에서 설치 없이 동작. 3.11은 설정 파일의 `tomllib` 때문 | 채택 |
| D3 | MCP 서버는 **시드로만** 남김 | stdio MCP 동시 제공 | Claude Code에서는 Bash+CLI로 충분. 표면이 둘이면 계약 유지 비용이 두 배. Desktop·Cowork 확장 시 CLI를 감싸는 얇은 어댑터로 추가 | 보류(시드) |
| D4 | 케이스는 **Markdown(서술) + JSONL 원장(증거·질문·결정·상태)** | 단일 JSON + 렌더링, 단일 Markdown | 사람과 모델 모두 Markdown 편집이 자연스럽다. 무결성이 필요한 이벤트는 CLI가 소유한다 | 채택 |
| D5 | 케이스는 기본 **로컬 전용**, 지식·시나리오·설정은 커밋 | 전부 커밋 | 글로벌 서비스의 로그·DB 결과에 개인정보가 섞인다. 공유는 정제 보고서로 | 채택 |
| D6 | 가드 훅은 **deny/ask만** 낸다 | 안전하다고 판정하면 allow로 프롬프트 생략 | 휴리스틱 판정으로 사용자 권한 체계를 넓히지 않는다 | 채택 |
| D7 | SQL 분류기는 **보안 경계가 아님**을 명시. 읽기전용 계정 전제 | 분류기만으로 라이브 쿼리 허용 | 문자열 분석은 우회될 수 있다. 다층 방어의 한 층일 뿐이다 | 채택 |
| D8 | 봇 테스트는 **선언형 시나리오 + 어댑터**(python / JSON-lines process) | 팀 봇 코드에 AI가 직접 작성 | 시나리오는 모델이 쓰기 쉽고 회귀 자산이 된다. 프로토콜은 어댑터에 격리. process 어댑터로 C#·C++ 봇도 이식 없이 감싼다 | 채택 |
| D9 | 검증용 **샌드박스 게임 서버** 동봉 (네트워크 없음) | 문서 예시만 | 도구 실측, 온보딩 데모, eval 픽스처를 하나로 해결 | 채택 |
| D10 | 데이터 테이블 정합성 **규칙 엔진** | v1 포함 | 포맷·규칙이 팀마다 다르다. v1은 `doc text`(xlsx/csv 읽기)까지만 하고, 첫 도입 후 실제 테이블 기준으로 설계한다 | 보류(시드) |
| D11 | **출처가 등급 상한을 정함** (manual ≤ 추론, report·review는 인용 시 추론, derived ≤ 전제) | 등급을 모델 자율에 맡김 | 설계 교차검증 H1: 자기 신고 등급은 쉽게 부풀려진다 | 채택 |
| D12 | **원인·효과는 재현 없이는 도출 불가**, 확인은 불가 | 일반 등급 규칙만 적용 | "재현이나 전후 대조 없는 원인 판정은 추론" 원칙을 기계로 강제 | 채택 |
| D13 | 상태는 **원장 이벤트**, front matter는 사본. 불일치는 린트 오류 | front matter만 사용 | 교차검증 H2: 손으로 상태를 바꾸는 게이밍을 드러낸다 | 채택 |
| D14 | 종료 사유별 게이트 + fixed는 **red→green**(같은 회귀 CHK에서 FAIL 실행이 PASS보다 먼저) | 섹션이 비어 있지 않은지만 확인 | 교차검증 H2: 형식적 PASS와 빈 리뷰 섹션을 막는다. data-fix·external 등은 재현이 불가능하므로 별도 게이트 | 채택 |
| D15 | 가드 마커는 **데이터 플레인 명령에서만**, 인용된 명령줄은 재귀 분석 | 명령 문자열 어디든 마커 매칭 | 교차검증 M3: 일상 명령에서 ask가 남발되면 사용자가 무심코 승인하는 습관이 생긴다 | 채택 |
| D16 | 인터프리터 실패·설정 오류·예외는 **ask로 실패** (bash 런처가 직접 JSON 출력) | 훅 에러(비차단)로 두기 | 교차검증 C1: Claude Code는 0/2 이외의 종료코드를 비차단으로 처리해 명령이 그대로 실행된다(fail-open) | 채택 |
| D17 | **사용자 레벨 설정** `~/.devloop/config.toml` 병합 | 워크스페이스 설정만 | 교차검증 C1: 워크스페이스 밖 저장소에서도 라이브 마커가 동작해야 한다 | 채택 |
| D18 | `db query`·`bot run`이 **CLI 안에서도 티어 정책**을 강제 | 훅에만 의존 | 교차검증 C2: CLI 내부 경로(프로브, 시나리오)는 훅이 볼 수 없다 | 채택 |
| D19 | 로그는 **줄 단위 디코딩**(UTF-8 → CP949 대체 집계), BOM·NUL 패턴으로 UTF-16 감지, 바이너리 건너뜀, 명령 원천·stdin 지원 | 파일 단위 인코딩 하나 | 교차검증 H3 + 실측: 한 파일에 UTF-8과 CP949가 섞이고, 디렉터리에 DB 파일이 섞인다 | 채택 |
| D20 | 경합 검사는 **반복 분포**로 보고하고 송신 편차를 출력 | 1회 병렬 실행 | 교차검증 H4: 배리어는 클라이언트 송신만 맞춘다 | 채택 |
| D21 | setup·report·retro는 **사용자 호출 전용** (`disable-model-invocation`) | 전부 자동 호출 | 교차검증 H5: 자동 호출 목록과 판단 비용을 줄인다(측정: 상시 ~1,200 토큰) | 채택 |
| D22 | 스펙·데이터 테이블 **텍스트 추출**(xlsx/docx/pptx/csv, 위치 표기) 포함 | 범위 밖 | 교차검증 M1: 설계검토의 입력을 읽지 못하면 REQ의 출처를 남길 수 없다 | 채택 |
| D23 | eval 픽스처는 **생성 스크립트에서 빌드**하고 테스트가 최신 상태를 검사 | 케이스에 사본 커밋 | eval 실행은 케이스 디렉터리를 읽을 수 없어 인라인 scaffold가 필요하다. 사본이 생기므로 단일 원천과 동기화 검사를 둔다 | 채택 |
| D24 | 최상위 `bin/` 대신 `scripts/` 런처 | 플러그인 `bin/`(PATH 자동 추가) | `bin/`이 있으면 claude.ai·Cowork가 플러그인을 설치하지 않는다(문서 확인). 스킬 본문에서 `${CLAUDE_PLUGIN_ROOT}` 경로가 치환된다 | 채택 |
| D25 | 독립 저장소로 분리 | REA 테스트 포크 안에 유지 | 내용상 REA와 무관하다. 이 세션은 지정 브랜치에만 푸시할 수 있어 `devloop/` 하위에 독립 저장소 형태로 두었다. `git subtree split --prefix=devloop`로 분리할 수 있다 | 제안(사용자 결정) |
| D26 | 원장에 **파일 잠금 + 이전 줄 해시 체인**, 아티팩트 해시 재검사 | 가드의 Edit/Write 차단만 | 구현 교차검증: 셸로 편집하면 탐지할 수 없었고, 동시 저장에서 ID가 중복됐다(재현) | 채택 |
| D27 | red→green은 **같은 재현 키**(같은 명령 또는 같은 시나리오 파일)에서 원장 순서로 판단 | 회귀 행에 FAIL·PASS 아무거나 | 교차검증: `false` 다음 `true`로 게이트가 통과됐고, 1초 해상도 시각 때문에 정상 순서가 거부됐다(재현) | 채택 |
| D28 | 비밀값은 `[secrets] env`에 **명시한 변수만** 기록 전에 가림 | 이름 패턴 추측, 가림 없음 | 명시된 민감값만 가린다는 원칙. `ev run` 인자에 전개된 비밀이 원장에 남았다(재현) | 채택 |
| D29 | stage/live 마커가 있는데 **분류할 수 없는 명령은 ask** (실행되는 문맥: 최상위, `bash -c`, 원격, `$(...)`) | 모르면 무결정 | 교차검증: 셸 문법 우회가 무결정으로 통과했다. 실행되지 않는 문자열(커밋 메시지 등)에는 적용하지 않아 오탐을 줄인다 | 채택 |
| D30 | 설정 병합: 가드 목록은 기본값 **확장**, 마커는 **합집합**, 티어 결정은 **더 엄격한 값** | 단순 덮어쓰기 | 교차검증: 워크스페이스 설정이 개인 live 마커와 기본 클라이언트 목록을 지웠다 | 채택 |
| D31 | TSV 행 너비가 헤더와 다르면 **조회를 거부** | 그대로 출력 | 교차검증: 값 안의 탭·개행 때문에 마스킹 열이 어긋나 개인정보가 노출됐다(재현) | 채택 |
| D32 | 남은 과제: 정책 설정 파일 변경 감시, 로그 원천 명령 전체 타임아웃, 셸 문법의 완전한 해석 | – | 가드는 실수 방지용이다. 설정 변경은 코드 리뷰로 다룬다 | 보류 |
